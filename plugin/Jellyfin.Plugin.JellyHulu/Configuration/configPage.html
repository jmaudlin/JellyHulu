Custom CSS

Appended after the theme, so it always wins. Redeclare any of the theme's tokens here — for example :root { --jh-accent: #FF4D8D; --jh-radius-card: 10px; }. Putting overrides here rather than in the server's Custom CSS box avoids the ordering trap where a rule above an @import is overridden by it.
